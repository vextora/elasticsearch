# Elasticsearch + Postgresql + Golang

## Deskripsi

Searching products with Suggestion using Elasticsearch + Postgresql + Golang

## Cara Menjalankan

1. Run make dev
2. Open Postman and use http://localhost:8080/health
3. All routes in main.go

## Kontak

Untuk pertanyaan lebih lanjut, hubungi tim pengembang.
